# Markdex

This is a simple CLI utility for updating / creating TOCs at Markdown files.

## Usage
```shell
markdex filename.md  # prints TOC at CLI.
markdex filename.md -e  # Edit the file updating / creating the TOC.
markdex filename.md --edit  # The same as above
markdex filename.md -o new_file.md  # Create new file with the updated/created TOC.
markdex filename.md --output new_file.md  # Same as above.
markdex filename.md -e --output new_file.md  # Same as above.
markdex filename.md -e -o new_file.md  # Same as above.
```
